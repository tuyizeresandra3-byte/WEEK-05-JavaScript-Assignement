# Week 05: JavaScript Control Flow & Pattern Challenges

## Overview
This project contains seven JavaScript challenges covering conditional statements, switch statements, loops, FizzBuzz, student results, pattern printing, and a number guessing game.

## How to Run Each Task

Run the six JavaScript files in the VS Code terminal using Node.js:

```bash
node control-flow/01-grade-decision.js
node control-flow/02-weekly-planner.js
node control-flow/03-loop-lab.js
node control-flow/04-fizzbuzz.js
node control-flow/05-student-results.js
node control-flow/06-pattern-printing.js

Open `control-flow/07-guessing-game.html` in a web browser to play the guessing game.

## Loops and Control Flow
- **if/else:** Used to check marks and assign grades.
- **switch:** Used to select a daily schedule.
- **for loop:** Used when the number of repetitions is known.
- **while loop:** Used for repeated actions while a condition is true.
- **continue:** Skips selected numbers in the loop.
- **Nested loops:** Used to print star and number patterns.

## Three Edge Cases Tested
1. Invalid grade marks, such as a mark below 0 or above 100.
2. Invalid day numbers, such as 0 or 8.
3. Invalid guessing-game input, such as letters, decimals, or numbers outside 1–100.
